Настоящее Соглашение регулирует использование Telegram-бота и сайта сервиса AraStars (далее — «Сервис»). Владельцем Сервиса является {{SELLER_NAME}}, ИНН {{SELLER_INN}} (далее — «Администрация»).

Начиная использовать Сервис, Пользователь принимает условия настоящего Соглашения. Если Пользователь не согласен с ними, он должен прекратить использование Сервиса.

1. Общие положения

  1. Соглашение дополняет Публичную оферту. В случае противоречия в части оказания услуг приоритет имеет Оферта.
  2. Использовать Сервис вправе лица, обладающие необходимой дееспособностью для совершения сделок.
  3. Сервис не является официальным продуктом Telegram FZ-LLC и не аффилирован с ним.

2. Аккаунт Пользователя

  1. Идентификация производится по аккаунту Telegram. Отдельная регистрация не требуется.
  2. Все действия, совершённые через аккаунт Telegram Пользователя, считаются совершёнными им лично.
  3. Пользователь самостоятельно обеспечивает безопасность доступа к своему аккаунту Telegram. Администрация не отвечает за последствия утраты Пользователем контроля над аккаунтом.

3. Правила использования

Пользователю запрещается:

  1. оплачивать заказы платёжными средствами, правом распоряжения которыми он не обладает;
  2. использовать Сервис для легализации доходов, полученных преступным путём, либо в иных противоправных целях;
  3. предпринимать действия, направленные на нарушение работоспособности Сервиса, включая автоматизированный сбор данных и создание чрезмерной нагрузки;
  4. намеренно вводить Администрацию в заблуждение относительно обстоятельств заказа или факта оказания услуги;
  5. создавать несколько аккаунтов для получения реферального вознаграждения за самого себя либо искусственно увеличивать его иным способом.

4. Внутренний баланс

  1. Сервис предоставляет Пользователю внутренний баланс для удобства оплаты последующих заказов.
  2. Баланс пополняется Пользователем и может быть использован исключительно для оплаты услуг внутри Сервиса.
  3. Средства на балансе не являются электронными денежными средствами и не начисляют процентов.
  4. При блокировке аккаунта по основаниям раздела 7 неиспользованный остаток баланса, внесённый Пользователем, подлежит возврату по его заявлению, за исключением сумм, начисленных в нарушение раздела 3.

5. Реферальная программа

  1. Пользователь получает персональную ссылку для приглашения новых пользователей.
  2. За заказы приглашённых пользователей начисляется вознаграждение на внутренний баланс в размере, указанном в Сервисе на момент начисления.
  3. Вывод вознаграждения доступен при накоплении суммы от 500 (пятисот) рублей и производится по заявке Пользователя после проверки Администрацией.
  4. Администрация вправе отказать в начислении или выводе вознаграждения и аннулировать его при выявлении признаков недобросовестных действий, в том числе указанных в п. 3.5.
  5. Условия реферальной программы могут быть изменены. Изменения не распространяются на вознаграждение, начисленное до их вступления в силу.

6. Выкуп Telegram Stars

  1. Сервис может выкупать Telegram Stars у Пользователей по цене, указанной в Сервисе на момент подачи заявки.
  2. Заявка на выкуп рассматривается Администрацией. Выкуп производится после подтверждения передачи Звёзд.
  3. Администрация вправе отказать в выкупе без объяснения причин до момента подтверждения заявки.

  1. Администрация вправе ограничить или прекратить доступ Пользователя к Сервису при нарушении настоящего Соглашения, при наличии признаков мошенничества либо по требованию уполномоченного органа.
  2. Денежные средства за оплаченные, но не оказанные услуги возвращаются Пользователю в порядке раздела «Возврат средств».
